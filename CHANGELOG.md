# Changelog

## Unreleased

### Added

- Linux daemon, command-line client and stdio MCP adapter for ingesting and
  querying operational logs and artifacts.
- Exact-byte reads, structured record queries, ranked text search and governed
  SPARQL using PurRDF.
- Expiring pins, archive-gated retirement and offline GTS verification and
  extraction.
- Rust producer SDK with console output, durable spool replay, explicit lossy
  delivery and bulk imports. The SDK is available separately on crates.io.
- Systemd deployment examples and a local quickstart.
